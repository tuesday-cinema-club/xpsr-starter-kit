# Apps

| App | What it is |
| --- | --- |
| [XPSR Director](director/README.md) | The four gates as a phone app. Writing help and first and last frames run on the workshop machine's GPU; motion comes from Google Flow through useapi.net, inside a daily credit budget. It also has a library of every file made, with its credit cost, and a live resources page. It packs the kit's `brief.md`, `shots.json`, `provenance.csv` and `audit.md`. |
